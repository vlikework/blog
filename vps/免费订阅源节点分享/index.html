订阅节点链接
#

  • Clash订阅地址(使用CDN链接,有延迟): 这个可以作为备用更新链接，毕竟延迟太久可能包含的节点早就失效了。
  • Clash订阅地址(原地址，需要通过代理访问): 更新及时，有效节点更多。
  • URI列表订阅地址(v2ray客户端使用): CND链接 == Github链接

Clash配置分享
#

下面配置为不会配置的用户准备的，不用修改任何配置，只需要在代理列表中选择可用节点就可以使用了。内部已经配置了免费的代理节点。

  • Clash启动配置 ：直接可以使用的配置，自带我分享的免费节点订阅源。
  • 带Relay中继规则的Clash启动配置：特殊指出就是增加了一个二级Relay中继规则，即网络请求走了两次代理转发，用途：1.解锁流媒体，2.拯救被国内封锁IP的代理节点。

自建代理方法
#

自己搭建VPS方法已经非常简单化了，通常只需要一个OneScript类的一键安装脚本就可以解决，只需要阅读一下文档说明就能学会。

推荐几个比较好用的搭建梯子的一键安装脚本工具

  • 3X-UI: 一个更好的面板 • 基于Xray Core构建（通过Web页面配置，所见即所得）
  • x-ui: 支持多协议多用户的 xray 面板（通过Web页面配置，所见即所得）
  • v2ray-agent: Xray、Tuic、hysteria2、sing-box 八合一一键脚本
  • 233boy/Xray: 最好用的 Xray 一键安装脚本 & 管理脚本

3X-UI安装方法:

bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)

v2ray-agent脚本下载方法:

支持快捷方式启动，安装完毕后，shell输入【vasma】即可打开脚本，脚本执行路径[/etc/v2ray-agent/install.sh]

# Github
wget -P /root -N --no-check-certificate "https://raw.githubusercontent.com/mack-a/v2ray-agent/master/install.sh" && chmod 700 /root/install.sh && /root/install.sh

# 官方网站【备用】
wget -P /root -N --no-check-certificate "https://www.v2ray-agent.com/v2ray-agent/install.sh" && chmod 700 /root/install.sh && /root/install.sh

这里不介绍详细的配置过程，需要的话可以访问Github官方文档了解，毕竟官方文档更为详细。

自建代理VPS的推荐选择
#

有了安装脚本后，我们需要选择一台VPS服务器实现我们的梯子。

首先，我们按下面用途分类：

  • 优质高速VPS（价格更高）: 选择电信CN2GIA线路/移动CMI线路/联通AS9929线路的VPS。
  • 超低价VPS(主打低价): 适合油管用户、日常搜索查询需求用户。
  • 解锁流媒体VPS(原生IP)：适合Netflix/TikTok/Youtube等流媒体解锁需求用户。

总结
#

VPS种类繁多，需求种类也个有不同，但永远也逃不出这样一个结论：

越是高质量VPS（大带宽/优质线路/大容量）就越贵

这并不是说，一定要买贵的，满足自己需要就可以了。举例来说：

  • 看youtube的王局拍岸，低价VPS足以满足：这类VPS每月流量多，网络线路延迟高一点，配合网络优化后，看视频影响可以接受，没必要上CN2GIA高价格线路的VPS。
  • 搭建个人服务平台：某些小程序的服务端，延迟要求要小，那就两种方案：1.地理位置靠近目标用户区，2.优质线路VPS(双程CN2GIA),前者价格低，后者价格高，同价位情况下，前者可以购买到配置更高的VPS。
  • 大容量存储服务器：本文列举的不包含大容量VPS，毕竟国内的免费云盘已经免费使用。假如使用大容量VPS作存储需要考虑冗余备份（就是要在两个VPS提供商购买容量一样的VPS），否则一旦VPS跑路或者数据丢失，后悔也来不及了。
